    What gets filled
    • projectMetadata — project info, PCR, sequencing, bioinformatics
    • sampleMetadata — one row per sample & field blank
    • experimentRunMetadata — one row per sample × assay

    Anything the report doesn't state is entered as "missing: not provided" (FAIRe wording), so nothing is guessed.

    Without an API key the tool uses built-in pattern matching. With a Claude key it can also read unusual report layouts.
