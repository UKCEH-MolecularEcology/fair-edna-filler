More sources: protocol, dataset, GitHub, BioProject optional · public links only

Only public records are downloaded and combined with the report; the report itself never leaves your computer. Some sites (often protocols.io) block downloads from web pages – if so, download the protocol PDF and add it under Extra files, or use the Python/Colab version.

Advanced: let Claude read the report off · not for confidential reports

Claude gives a second opinion and can read unusual layouts and other languages. Every value it returns must quote the report; values whose quote can't be found are discarded, and anything it adds is marked for checking. Leave this off and nothing leaves your computer.

      What gets filled
      • projectMetadata — project info, PCR, sequencing, bioinformatics
      • sampleMetadata — one row per sample & field blank
      • experimentRunMetadata — one row per sample × assay

      Values with a clear source in the report, that pass the FAIRe format checks, are accepted automatically. You only look at the ones flagged. Anything the report doesn't state is entered as "missing: not provided" (FAIRe wording).

      Profiles: after filling, Save my corrections downloads a small file. Load it next time and the same corrections are applied for you.

      Private by default: the built-in reader runs entirely in your browser. Claude is only used if you switch it on for a non-confidential report.
