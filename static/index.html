What it fills

  • projectMetadata – all project, PCR, sequencing & bioinformatics fields
  • sampleMetadata – one row per sample / field blank
  • experimentRunMetadata – one row per sample × assay

Fields not found in the report are filled with approved FAIRe missing-value wording so the workbook is always valid.

AI vs rule-based parsing

Without a Claude API key the tool uses regular-expression rules (reliable for standard Defra/UKCEH report formats). With a key it sends the report text to Claude Haiku for richer, more flexible extraction — better for unusual formats.
