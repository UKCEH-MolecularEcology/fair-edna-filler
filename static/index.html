Run in Google Colab — no installation needed

Google Colab runs the extraction entirely in the cloud. You upload your report and template directly in the notebook, add your Claude API key, and download the filled workbook — no Python or terminal required.

    What gets filled
    • projectMetadata — project info, PCR, sequencing, bioinformatics
    • sampleMetadata — one row per sample & field blank
    • experimentRunMetadata — one row per sample × assay

    Fields not found in the report are filled with approved FAIRe missing-value wording so the workbook always passes the FAIRe-fier validator.

    AI vs rule-based: Without a Claude API key the tool uses regular-expression rules. With a key, Claude Haiku reads the full report and returns a richer extraction.
